Block–Tiwari FS-FRI 指标下的 Parano1d

在 Block–Tiwari 的非交互式 FRI 模型下，当前 Parano1d History 参数能提供怎样的安全性？本文逐步展开其分析方法，并分别推导可证明估计与基于猜想的估计。

摘要

Block 与 Tiwari 通过随机预言机查询的期望工作量 Q/epsilon 定义非交互式 FRI 的具体安全性。本文把当前 Parano1d History 参数映射到该定义，分别推导已证明和基于猜想的 RBR 输入，并精确求解整数优化。

安全位表格背后的问题

FRI 是针对 Reed–Solomon 码的接近性证明，也是许多透明证明系统的核心组件。FRI 原本是一种交互式预言机证明（IOP）：验证者发送随机挑战值，只读取证明者大型预言机中的少量位置。Fiat–Shamir 变换通过随机预言机导出挑战值，从而消除交互。一旦完成这项变换，相关资源便不再只是单份交互记录中的 FRI 查询数。恶意证明者可以反复查询随机预言机，筛选有利的交互记录并重复攻击。

Block 与 Tiwari 在 On the Concrete Security of Non-interactive FRI 中为这类攻击给出了明确的工作量度量。他们从交互式协议的逐轮（round-by-round，RBR）可靠性误差出发，应用 Fiat–Shamir 编译器界，再对所有随机预言机查询预算最小化期望攻击工作量。

本文只回答一个问题：按照同一定义、同一 256 位预言机输出设置和同一整数位展示方式，当前 Parano1d History 参数会得到怎样的一行安全性数据？ 已证明的 RBR 前提与基于 Block–Tiwari 猜想 1 的前提将分别推导、分别报告。

从交互式可靠性到期望攻击工作量

设恶意证明者至多向下列随机预言机发出 QQQ 次经典查询：

H:{0,1}∗⟶{0,1}κ.H:\{0,1\}^{*}\longrightarrow\{0,1\}^{\kappa}.H:{0,1}∗⟶{0,1}κ.

若底层交互式协议的 RBR 可靠性误差为 εRBR\varepsilon_{\mathrm{RBR}}εRBR​，Block 与 Tiwari 的引理 1 给出如下自适应非交互式随机预言机证明（NIROP）误差：

εBT(Q,κ)=min⁡ ⁣{1,  QεRBR+3(Q2+1)2κ}.\varepsilon_{\mathrm{BT}}(Q,\kappa) =\min\!\left\{ 1,\; Q\varepsilon_{\mathrm{RBR}} +\frac{3(Q^2+1)}{2^\kappa} \right\}.εBT​(Q,κ)=min{1,QεRBR​+2κ3(Q2+1)​}.

第一项把交互式 RBR 误差计入 QQQ 次预言机尝试。二次项是通过 Fiat–Shamir 编译公币协议所付出的有限代价。外层最小值把成功概率截断在一以内。

定义 2 衡量的是工作量，而不是某个选定预算下一次尝试的成功概率。一次包含 QQQ 次查询、成功概率为 εBT(Q,κ)\varepsilon_{\mathrm{BT}}(Q,\kappa)εBT​(Q,κ) 的攻击，经重复后要以接近一的概率得到伪造，所需随机预言机查询的期望数为

W(Q)=QεBT(Q,κ).W(Q)=\frac{Q}{\varepsilon_{\mathrm{BT}}(Q,\kappa)}.W(Q)=εBT​(Q,κ)Q​.

因此，具体安全性指数为

λBT=log⁡2 ⁣(min⁡Q∈Z≥1W(Q)).\lambda_{\mathrm{BT}} =\log_2\!\left( \min_{Q\in\mathbb Z_{\ge1}} W(Q) \right).λBT​=log2​(Q∈Z≥1​min​W(Q)).

按照该定义，协议具有 λ\lambdaλ 位安全性，当且仅当对每个正整数 QQQ 都有 W(Q)≥2λW(Q)\ge2^\lambdaW(Q)≥2λ。对 QQQ 的最小化本身就是指标的一部分，不能只选择一个方便的敌手查询预算。

同一参数集的两种 RBR 前提

已证明的 History RBR 界

当前 History 定理分析 GF(2128) 上的公币 IOP，其中承诺已替换为对预言机的直接访问。在相对距离 2/52/52/5 下，任何保留到最终查询动作的候选，与初始 32 列预言机的一致位置比例至多为 3/53/53/5；唯一例外是此前某个验证者挑战值落入已明确计数的异常集合。

32 列被打包成固定的 32 次扩域上的一个 Reed–Solomon 码字。重数为 5 的列表译码至多留下 11 个初始候选。列表相关一致性（list-correlated agreement）把后续折叠产生的任一候选追溯到这份固定列表；在代数挑战值处切换候选时，对各候选的根集合取并集并计入代价，而不是假定候选始终不变。单个候选的最大代数次数为 127。

猜想 1 前提

在基于猜想的列中，Block 与 Tiwari 假定目前已知的最佳信息论 FRI 攻击是最优的。相应表达式为

εRBRconj=max⁡ ⁣{1∣F∣,ρℓ}.\varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{\frac1{|\mathbb F|},\rho^\ell\right\}.εRBRconj​=max{∣F∣1​,ρℓ}.

代入当前域、码率和查询数，得到

εRBRconj=max⁡ ⁣{2−128,(1/4)125}=max⁡ ⁣{2−128,2−250}=2−128.\boxed{ \varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{2^{-128},(1/4)^{125}\right\} =\max\!\left\{2^{-128},2^{-250}\right\} =2^{-128}.}εRBRconj​=max{2−128,(1/4)125}=max{2−128,2−250}=2−128.​

最大值由域大小分支决定。因此，两类 History 在后续计算中具有相同的已证明取值，也具有相同的猜想取值。

全局优化为何只需检查两个整数

记 a=εRBRa=\varepsilon_{\mathrm{RBR}}a=εRBR​、b=3/2256b=3/2^{256}b=3/2256。在概率达到截断值之前，

两列数值说明了什么

在 2024 年参数快照中，Parano1d 的可证明数值高于除 lambdaworks 之外的所有数值，包括 Miden 128 位配置的 67。在三组 lambdaworks 参数中，它高于 80 位配置，低于 100 位和 128 位配置。Block 与 Tiwari 特别指出，lambdaworks 是其快照中唯一一个所有可证明数值都接近对应目标的系统族。

Parano1d 基于猜想的指数比 128 位目标低 1.203373854422…1.203373854422\ldots1.203373854422… 位，向下取整后显示为 126。两个 Parano1d 精确指数之差为

在该方法中，这一差值具有明确含义：把已证明的 RBR 前提 (3/5)125(3/5)^{125}(3/5)125 替换为猜想 1 的 2−1282^{-128}2−128 前提时，具体 FS-FRI 安全性增加了这么多。它不是取整造成的误差，也没有被隐藏在目标列中。

复现整数证书

公开工作台中的精确优化器位于 crates/block-tiwari-rom，两项结果均由回归测试固定：

git clone https://github.com/ignotusnemo/parano1d-qrom.git
cd parano1d-qrom

cargo test --release --locked --workspace
cargo run --release --locked -p scenarios -- block-tiwari-rom

两个发布位数的判定均不依赖浮点数。复现只需任意精度整数与四个步骤：

  1. 根据选定的 RBR 前提写出未截断误差的分子；
  2. 用二分查找求出分子仍小于分母的最大正整数 Q0Q_0Q0​；
  3. 以精确有理数比较 W(Q0)W(Q_0)W(Q0​) 与 Q0+1Q_0+1Q0​+1；
  4. 把较小的有理数与相邻的 2 的幂比较。

对已证明的前提，两次二次幂检验无需除法即可写为

292N(Q0)≤Q0D<293N(Q0).2^{92}N(Q_0)\le Q_0D\lt2^{93}N(Q_0).292N(Q0​)≤Q0​D<293N(Q0​).

对基于猜想的前提，把 DDD 替换为 22562^{256}2256，把 N(Q)N(Q)N(Q) 替换为 Q2128+3(Q2+1)Q2^{128}+3(Q^2+1)Q2128+3(Q2+1)。上文给出的边界整数足以作为独立 SageMath、Rust、Python 或其他计算机代数实现的回归向量。作者的 SageMath 仓库提供了其更完整参数研究的参考实现。
