The question behind a security-bit table

FRI is a proximity proof for Reed–Solomon codes and a core component of many transparent proof systems. Its original form is an interactive oracle proof (IOP): the verifier sends random challenges and inspects a small number of positions in large prover oracles. The Fiat–Shamir transformation removes that interaction by deriving the challenges from a random oracle. Once this transformation is applied, the relevant resource is no longer only the number of FRI queries inside one transcript. A cheating prover may query the random oracle many times, choose a favorable transcript and repeat the attack.

Block and Tiwari gave this attack an explicit work measure in On the Concrete Security of Non-interactive FRI. They start from a round-by-round (RBR) soundness error for the interactive protocol, apply the Fiat–Shamir compiler bound and minimize expected attack work over every random-oracle query budget.

This study asks one question: what security row do the current Parano1d History parameters obtain under the same definition, the same 256-bit oracle-output setting and the same whole-bit display convention? The proved RBR premise and the premise based on Block–Tiwari Conjecture 1 are derived and reported separately.

From interactive soundness to expected attack work

Let a malicious prover make at most Q classical queries to a random oracle

H:\{0,1\}^{*}\longrightarrow\{0,1\}^{\kappa}.

If the underlying interactive protocol has RBR soundness error \varepsilon_{\mathrm{RBR}}, Lemma 1 of Block and Tiwari gives the following adaptive non-interactive random-oracle proof (NIROP) error:

\varepsilon_{\mathrm{BT}}(Q,\kappa) =\min\!\left\{ 1,\; Q\varepsilon_{\mathrm{RBR}} +\frac{3(Q^2+1)}{2^\kappa} \right\}.

The first term charges the interactive RBR error across Q oracle attempts. The quadratic term is the finite cost of compiling the public-coin interaction through Fiat–Shamir. The outer minimum keeps the success probability at most one.

Definition 2 measures work rather than the success probability of one selected budget. A Q-query attempt that succeeds with probability \varepsilon_{\mathrm{BT}}(Q,\kappa) requires

W(Q)=\frac{Q}{\varepsilon_{\mathrm{BT}}(Q,\kappa)}

expected random-oracle queries to obtain a forgery with probability close to one by repetition. The concrete security exponent is therefore

\lambda_{\mathrm{BT}} =\log_2\!\left( \min_{Q\in\mathbb Z_{\ge1}} W(Q) \right).

A protocol has \lambda bits under this definition exactly when W(Q)\ge2^\lambda for every positive integer Q. The minimization over Q is part of the metric; choosing a convenient adversarial budget is not.

Two RBR premises for one parameter set

The proved History RBR bound

The current History theorem analyzes the decommitted public-coin IOP over GF(2128). At relative distance 2/5, every candidate retained for the final query move agrees with the initial 32-column oracle on at most a 3/5 fraction unless an earlier verifier challenge falls into a counted exceptional set.

The 32 columns are packed into one Reed–Solomon word over a fixed degree-32 extension. Multiplicity-five list decoding leaves at most eleven initial candidates. List-correlated agreement carries any later fold candidate back to that fixed list; switching among candidates at an algebraic challenge is then paid by a union of their root sets rather than assumed away. The largest per-candidate algebraic degree is 127.

The complete-path term is the largest of these four quantities for both classes. The generalized RBR knowledge error is consequently

\varepsilon_{\mathrm{RBR}}^{\mathrm{proved}} =\max\!\left\{ \frac{U_5(n)}{2^{128}}, \frac{11\cdot127}{2^{128}}, \frac{11\cdot24}{2^{128}}, \left(\frac35\right)^{125} \right\} =\left(\frac35\right)^{125}.

The extractor returns a valid History witness outside these bad-response events. Acceptance of a false statement is therefore contained in extractor failure, so the same quantity is a valid RBR soundness premise for the Block–Tiwari compiler:

\boxed{ \varepsilon_{\mathrm{RBR}}^{\mathrm{proved}} =\left(\frac35\right)^{125}.}

The Conjecture 1 premise

For the conjectured column, Block and Tiwari model the best known information-theoretic FRI attack as optimal. Their current expression is

\varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{\frac1{|\mathbb F|},\rho^\ell\right\}.

Substituting the current field, rate and query count gives

\boxed{ \varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{2^{-128},(1/4)^{125}\right\} =\max\!\left\{2^{-128},2^{-250}\right\} =2^{-128}.}

The field branch controls this premise. Both History classes therefore enter the remaining calculation with the same proved value and the same conjectured value.

Why the global optimization reduces to two integers

Write a=\varepsilon_{\mathrm{RBR}} and b=3/2^{256}. Before the probability cap is reached,

W(Q) =\frac{Q}{aQ+b(Q^2+1)} =\frac1{a+b(Q+1/Q)}.

For positive integer Q, the quantity Q+1/Q is nondecreasing. Thus W(Q) is nonincreasing throughout the uncapped region. After the error reaches one, W(Q)=Q and is strictly increasing. The global minimum is therefore one of two adjacent integers: the largest Q_0 whose uncapped error is below one, or Q_1=Q_0+1, the first capped point.

This argument covers every positive integer query budget. Exact integer binary search locates the boundary, and one rational comparison selects between the two candidates.

What the two columns show

The provable Parano1d value is higher than every non-lambdaworks value in the 2024 snapshot, including 67 for the Miden 128-bit configuration. Among the three lambdaworks rows, it is above the 80-bit configuration and below the 100- and 128-bit configurations. Block and Tiwari singled out lambdaworks as the only family in their snapshot whose proved values stayed close to all of its targets.

The conjectured Parano1d exponent is 1.203373854422\ldots bits below the 128-bit target, which appears as 126 after flooring. The difference between the two exact Parano1d exponents is

126.796626145577\ldots -92.120699270775\ldots =34.675926874802\ldots\ \text{bits}.

That gap has a precise meaning in this methodology: it is the additional concrete FS-FRI security obtained when the proved RBR premise (3/5)^{125} is replaced by Conjecture 1's 2^{-128} premise. It is not a rounding artifact and it is not hidden inside the target column.

Reproducing the integer certificates

The public workbench contains the exact optimizer in crates/block-tiwari-rom and pins both results with regression tests:

git clone https://github.com/ignotusnemo/parano1d-qrom.git
cd parano1d-qrom

cargo test --release --locked --workspace
cargo run --release --locked -p scenarios -- block-tiwari-rom

No floating-point value is used to decide either reported bit. A reproduction needs arbitrary-precision integers and performs four steps:

  1. instantiate the uncapped numerator for the selected RBR premise;
  2. binary-search the largest positive integer Q_0 for which that numerator is smaller than its denominator;
  3. compare W(Q_0) and Q_0+1 as exact rationals;
  4. compare the winning rational against consecutive powers of two.

For the proved premise, the two power-of-two tests can be written without division as

2^{92}N(Q_0)\le Q_0D\lt2^{93}N(Q_0).

For the conjectured premise, replace D by 2^{256} and N(Q) by Q2^{128}+3(Q^2+1). The boundary integers printed above are sufficient regression vectors for an independent SageMath, Rust, Python or computer-algebra implementation. The authors' SageMath repository supplies the reference implementation of their broader parameter study.
