Как читать строку Parano1d

128 бит — заявленный целевой уровень, а не вычисленная граница. Значение 92 бита использует доказанную RBR-предпосылку History. Значение 126 бит получается после замены этой предпосылки Гипотезой 1 Block–Tiwari. Оба числа вычислены по одной формуле ожидаемой трудоёмкости: 92-битное значение опирается на доказанную предпосылку, 126-битное — на гипотезу.

Что стоит за таблицей битов безопасности

FRI — это доказательство близости для кодов Рида—Соломона и один из основных компонентов многих прозрачных систем доказательств. Изначально FRI является интерактивным доказательством с оракулом (IOP): проверяющая сторона посылает случайные вызовы и читает небольшое число позиций в больших оракулах доказывающей стороны. Преобразование Fiat–Shamir устраняет интерактивность, получая вызовы из случайного оракула. После такого преобразования важным ресурсом становится не только число FRI-запросов внутри одной транскрипции. Недобросовестная доказывающая сторона может многократно обращаться к случайному оракулу, выбирать выгодную транскрипцию и повторять атаку.

Block и Tiwari задали явную меру этой работы в статье On the Concrete Security of Non-interactive FRI. Они начинают с пораундовой (round-by-round, RBR) ошибки корректности интерактивного протокола, применяют границу компилятора Fiat–Shamir и минимизируют ожидаемую трудоёмкость атаки по всем бюджетам запросов к случайному оракулу.

В этом исследовании поставлен один вопрос: какую строку безопасности дают текущие параметры Parano1d History по тому же определению, при той же 256-битной длине выхода оракула и с тем же представлением результатов в целых битах? Доказанная RBR-предпосылка и предпосылка на основе Гипотезы 1 Block–Tiwari выводятся и публикуются отдельно.

От интерактивной корректности к ожидаемой трудоёмкости атаки

Пусть злоумышленник делает не более Q классических запросов к случайному оракулу

H:\{0,1\}^{*}\longrightarrow\{0,1\}^{\kappa}.

Если RBR-ошибка корректности исходного интерактивного протокола равна \varepsilon_{\mathrm{RBR}}, то Лемма 1 Block и Tiwari даёт следующую ошибку адаптивного неинтерактивного доказательства в модели случайного оракула (NIROP):

\varepsilon_{\mathrm{BT}}(Q,\kappa) =\min\!\left\{ 1,\; Q\varepsilon_{\mathrm{RBR}} +\frac{3(Q^2+1)}{2^\kappa} \right\}.

Первое слагаемое учитывает интерактивную RBR-ошибку на протяжении Q попыток обращения к оракулу. Квадратичное слагаемое — конечная цена компиляции протокола с публичными случайными монетами посредством Fiat–Shamir. Внешний минимум ограничивает вероятность успеха единицей.

Определение 2 измеряет работу, а не вероятность успеха при одном выбранном бюджете. Попытка с Q запросами и вероятностью успеха \varepsilon_{\mathrm{BT}}(Q,\kappa) при повторении требует в среднем

W(Q)=\frac{Q}{\varepsilon_{\mathrm{BT}}(Q,\kappa)}

запросов к случайному оракулу, чтобы получить подделку с вероятностью, близкой к единице. Поэтому показатель конкретной безопасности равен

\lambda_{\mathrm{BT}} =\log_2\!\left( \min_{Q\in\mathbb Z_{\ge1}} W(Q) \right).

Протокол имеет \lambda бит безопасности по этому определению тогда и только тогда, когда W(Q)\ge2^\lambda для каждого положительного целого Q. Минимизация по Q является частью метрики: произвольно выбрать удобный бюджет злоумышленника нельзя.

Текущий набор параметров History

Параметры протокола сверены с версией Parano1d 2cce53fc31a0bc173661bf5e07efaa56d8dc661b. HistoryStep — рекурсивное доказательство точного перехода блока от родительского State к дочернему State. B64 и B255 проверяют одно и то же отношение перехода, но рассчитаны соответственно на 64 и 255 пользовательских страниц транзакций. Две RBR-предпосылки для одного набора параметров

Доказанная RBR-граница History

Теорема для текущего History рассматривает IOP над GF(2128) с публичными случайными монетами, где обязательства заменены прямым доступом к оракулам. При относительном расстоянии 2/5 каждый кандидат, сохранившийся до финального шага запросов, совпадает с исходным 32-столбцовым оракулом не более чем в доле 3/5 позиций, если только один из более ранних вызовов проверяющей стороны не попал в явно учтённое исключительное множество.

Тридцать два столбца упаковываются в одно слово Рида—Соломона над фиксированным расширением степени 32. Списочное декодирование кратности пять оставляет не более одиннадцати исходных кандидатов. Теорема list-correlated agreement — коррелированного согласия списков — связывает любой кандидат после свёрток с этим фиксированным списком. Переключение между кандидатами на алгебраическом вызове оплачивается объединением их множеств корней, а не отбрасывается предположением о фиксированном кандидате. Наибольшая алгебраическая степень для одного кандидата равна 127.

Для обоих классов наибольшим из четырёх значений оказывается слагаемое полных путей. Поэтому обобщённая RBR-ошибка знания равна

\varepsilon_{\mathrm{RBR}}^{\mathrm{proved}} =\max\!\left\{ \frac{U_5(n)}{2^{128}}, \frac{11\cdot127}{2^{128}}, \frac{11\cdot24}{2^{128}}, \left(\frac35\right)^{125} \right\} =\left(\frac35\right)^{125}.

Вне этих событий плохого ответа экстрактор возвращает корректный свидетель History. Поэтому принятие ложного утверждения содержится в событии неудачи экстрактора, и та же величина служит допустимой RBR-предпосылкой корректности для компилятора Block–Tiwari:

\boxed{ \varepsilon_{\mathrm{RBR}}^{\mathrm{proved}} =\left(\frac35\right)^{125}.}

Предпосылка из Гипотезы 1

Для столбца при гипотезе Block и Tiwari считают оптимальной лучшую известную информационно-теоретическую атаку на FRI. Используется выражение

\varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{\frac1{|\mathbb F|},\rho^\ell\right\}.

Подстановка текущего поля, скорости и числа запросов даёт

\boxed{ \varepsilon_{\mathrm{RBR}}^{\mathrm{conj}} =\max\!\left\{2^{-128},(1/4)^{125}\right\} =\max\!\left\{2^{-128},2^{-250}\right\} =2^{-128}.}

Максимум определяется ветвью размера поля. Поэтому оба класса History входят в дальнейший расчёт с одинаковой доказанной величиной и одинаковой величиной при гипотезе.

Почему глобальная оптимизация сводится к двум целым числам

Обозначим a=\varepsilon_{\mathrm{RBR}} и b=3/2^{256}. Пока вероятность не отсечена единицей,

W(Q) =\frac{Q}{aQ+b(Q^2+1)} =\frac1{a+b(Q+1/Q)}.

Для положительных целых Q величина Q+1/Q не убывает. Следовательно, W(Q) не возрастает на всём участке до отсечения. После достижения ошибки, равной единице, W(Q)=Q и строго возрастает. Поэтому глобальный минимум находится в одной из двух соседних точек: в наибольшем Q_0, где неотсечённая ошибка ещё меньше единицы, либо в Q_1=Q_0+1 — первой точке с отсечением.

Это рассуждение охватывает все положительные целые бюджеты запросов. Граница находится точным целочисленным двоичным поиском, после чего один рациональный тест выбирает из двух кандидатов.

Точное вычисление двух столбцов

Доказуемая безопасность FS-FRI

Для a=(3/5)^{125} положим

D=5^{125}2^{256}, \qquad N(Q)=Q3^{125}2^{256}+3(Q^2+1)5^{125}.

Неотсечённая ошибка в точности равна N(Q)/D. Целочисленное сравнение даёт единственную границу:

Q0 = 5,383,859,304,820,033,230,077,561,761   и N(Q0) < D
Q1 = 5,383,859,304,820,033,230,077,561,762   и N(Q1) ≥ D

В точке Q_0:

epsilon_BT(Q0) = 0.999999999999999999999999999827291815635045301984…
W(Q0)          = 5,383,859,304,820,033,230,077,561,761.929836565411835132…

Точные рациональные сравнения доказывают W(Q_0)\lt Q_1 и

2^{92}\le W(Q_0)\lt2^{93}.

Следовательно, Q_0 — глобальная точка минимума, сертифицированное целое значение равно 92, а десятичное представление показателя составляет

\boxed{\lambda_{\mathrm{BT}}^{\mathrm{proved}} =92{,}120699270775770802\ldots\ \text{бита}.}

Безопасность FS-FRI при гипотезе

При a=2^{-128} неотсечённая ошибка имеет точную целочисленную форму

\varepsilon_{\mathrm{BT}}^{\mathrm{conj}}(Q) =\frac{Q2^{128}+3(Q^2+1)}{2^{256}}.

Два соседних целых числа на границе отсечения равны

Q0 = 147,770,525,858,126,068,760,353,057,306,253,383,503
Q1 = 147,770,525,858,126,068,760,353,057,306,253,383,504

Q0·2^128 + 3(Q0^2+1) <  2^256
Q1·2^128 + 3(Q1^2+1) ≥ 2^256

Неотсечённый кандидат снова даёт меньшую работу:

epsilon_BT(Q0) = 0.999999999999999999999999999999999999995931834736…
W(Q0)          = 147,770,525,858,126,068,760,353,057,306,253,383,503.601154920268…

Точное сравнение даёт W(Q_0)\lt Q_1 и

2^{126}\le W(Q_0)\lt2^{127}.

Сертифицированное целое значение равно 126, а десятичное представление показателя составляет

\boxed{\lambda_{\mathrm{BT}}^{\mathrm{conj}} =126{,}796626145577656957\ldots\ \text{бита}.}

Что показывают два столбца

Доказуемое значение Parano1d выше каждого значения в срезе 2024 года, кроме lambdaworks, включая 67 для 128-битной конфигурации Miden. Среди трёх строк lambdaworks оно выше 80-битной конфигурации и ниже конфигураций на 100 и 128 бит. Block и Tiwari отдельно отмечают lambdaworks как единственное семейство в своём срезе, у которого доказанные значения остаются близки ко всем трём целям.

Показатель Parano1d при гипотезе на 1{,}203373854422\ldots бита ниже цели 128 бит, что после взятия целой части отображается как 126. Разность точных показателей Parano1d равна

126{,}796626145577\ldots -92{,}120699270775\ldots =34{,}675926874802\ldots\ \text{бита}.

В этой методике разность имеет точный смысл: столько дополнительной конкретной безопасности FS-FRI получается при замене доказанной RBR-предпосылки (3/5)^{125} на предпосылку 2^{-128} из Гипотезы 1. Это не эффект округления и не величина, скрытая в столбце цели.

Воспроизведение целочисленных сертификатов

В публичном стенде точный оптимизатор находится в crates/block-tiwari-rom, а оба результата закреплены регрессионными тестами:

git clone https://github.com/ignotusnemo/parano1d-qrom.git
cd parano1d-qrom

cargo test --release --locked --workspace
cargo run --release --locked -p scenarios -- block-tiwari-rom

Ни одно значение с плавающей точкой не участвует в выборе публикуемого целого числа. Для воспроизведения достаточно целых чисел произвольной точности и четырёх шагов:

  1. задать числитель неотсечённой ошибки для выбранной RBR-предпосылки;
  2. двоичным поиском найти наибольшее положительное целое Q_0, при котором числитель меньше знаменателя;
  3. точно как рациональные числа сравнить W(Q_0) и Q_0+1;
  4. сравнить выигравшее рациональное число с соседними степенями двойки.

Для доказанной предпосылки две проверки степеней двойки записываются без деления:

2^{92}N(Q_0)\le Q_0D\lt2^{93}N(Q_0).

Для предпосылки при гипотезе нужно заменить D на 2^{256}, а N(Q) — на Q2^{128}+3(Q^2+1). Напечатанных выше целых чисел на границе достаточно как регрессионных векторов для независимой реализации на SageMath, Rust, Python или в другой системе компьютерной алгебры. Репозиторий авторов на SageMath содержит эталонную реализацию их более широкого анализа параметров.
