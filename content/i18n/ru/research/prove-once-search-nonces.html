На каком этапе nonce должен входить в доказательство?

State — аутентифицированный набор текущих непотраченных выходов и счётчиков консенсуса. HistoryStep — рекурсивное доказательство точного перехода блока от родительского State к дочернему. Оно подтверждает дорогостоящую семантическую работу, тогда как proof of work изменяет только 128-битный nonce — поле заголовка, которое майнер перебирает при поиске. Если включить nonce в рекурсивное утверждение, каждый кандидат изменит само утверждение, и дорогое доказательство нельзя будет подготовить заранее.

Семантическая проекция сохраняет точный порядок полей заголовка блока и пропускает только nonce. Мутационные тесты независимо изменяют каждое поле: изменение nonce обязано сохранять семантический ID, изменение любого другого поля — менять его.

Когда nonce удовлетворяет целевому значению PoW, узел выполняет одну нативную проверку и убеждается, что заголовок с найденным nonce указывает ту же доказанную границу между родительским и дочерним State, что и семантический шаблон. Затем полный блок и терминал фиксируются атомарно.

Почему разделение не освобождает остальные поля

Рекурсивное доказательство исключает nonce, но не целевое значение майнинга и не семантические поля перехода. Нативное правило принятия требует, чтобы семантический ID терминала и заголовок-кандидат совпадали по всем полям, кроме nonce. ID блока с nonce остаётся идентификатором связи в цепочке.

Разделение доменов не позволяет интерпретировать одну последовательность поглощения данных одновременно как семантический и канонический ID блока.

Результат

Граница майнинга

Дорогостоящая работа доказательства выполняется один раз для фиксированного шаблона блока. Дешёвый поиск nonce может изменять единственное поле, намеренно исключённое из этого утверждения.

Этот шаблон применим везде, где дорогое доказательство подтверждает детерминированный объект, а отдельный поиск изменяет одно явно несемантическое поле. Правило принятия обязано вновь связать победивший результат поиска со всеми полями, зафиксированными доказательством.
